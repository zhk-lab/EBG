# Results

Compact aggregate records and plotting inputs belong here. Full predictions,
responses, and judge traces belong in an external artifact release or the ignored
local `outputs/` directory.

Existing numeric tables are retained in [benchmark results](../docs/benchmark_results.md)
and [judge agreement](../docs/judge_agreement.md), with a compact
[CSV export](main/README.md). Layout migration does not
change their values. [Release notes](../docs/release_notes.md) list outstanding
paper-version alignment questions.

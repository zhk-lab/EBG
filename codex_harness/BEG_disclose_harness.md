**整体流程**

```text
Hook 持续记录会话和代码状态
        ↓
Harness 在关键节点主动触发核对：
① 准备采用改进结果或对外汇报结果时
② 执行受阻、准备换方案或降低验证范围时
③ 关键要求不明确，需要作出影响结果的重要假设时
        ↓
检查是否已有适用的核对结果：
要求、代码、实验条件、证据或声明范围有变化 → 核对受影响部分
已核对且相关内容未变 → 复用结果，避免重复核对和披露
        ↓
beg_context 返回相关要求、Trace、关键代码及关联配置／来源材料
        ↓
Codex 核对要求、拟采用或汇报的结果及其证据
        ↓
证据不足 → beg_evidence 补查或展开冻结材料
        ↓
存在影响结论或后续决策的问题 → 主动说明问题、影响及证据
没有值得披露的问题 → 继续任务，不额外提醒
```

触发类型可以归为三类：

| 触发类型 | 包括哪些情况 | 默认返回哪些材料 |
|---|---|---|
| **结果采用或汇报** | 保留改进结果、宣布验证通过、汇报完成 | 相关要求、声明、执行与验证 Trace，以及对应代码、配置和输入来源材料 |
| **执行受阻或方案调整** | 验证失败、Plan 行不通、准备换方法、降低验证范围或跳过步骤 | 受阻 Trace、替代方案、相关要求和 Plan 步骤，以及涉及的实现证据 |
| **关键要求不明确** | Plan 遗漏或表述含糊，需要作出影响实现的重要假设 | 相关要求、Plan 上下文、拟采用的解释，以及会影响该解释的代码和配置 |

“Plan 行不通要换方式”和“Plan 没说清楚但影响实现”，分别属于第二、第三类。**普通实现细节不必触发；可能影响目标、范围、实验可比性或交付结果的选择才需要。**

具体流程可以简化为：

1. **触发并保存状态。** 记录触发类型、相关执行或 Plan 步骤、拟作出的声明或决定，同时保存当前 Repo 快照。

2. **beg_context 默认附带证据。** 以关联调用、相关要求和 Plan 为起点，返回 Trace、关键代码片段及引用到的配置／来源材料，并给出相应类型的审查重点和 Skill 的通用 autoresearch 原则。关联表可附唯一编号列的候选连接、分组计数与原文行；这些关系不自动证明实际使用或违规。较大材料提供展开入口。已有检查点复用冻结证据，不重新采集。

3. **Codex 判断。** 同时核对声明、要求、实际执行及实现条件。Autoresearch 任务按通用实验流程审查，不能只确认数字一致或命令成功。证据足够时直接判断是否需要披露。

4. **beg_evidence 用于补查。** 直接展开已返回的证据引用；或提交具体疑问，可附 Prompt／Trace／Plan 或已返回代码的原文引用来缩小范围，省略引用时使用检查点原始上下文。补取代码与关联材料，必要时对比历史版本。查询仍使用触发时保存的快照；问题和代码引用不作为用户要求或已证实的问题。

5. **披露或继续。** 有影响任务结论的问题，说明问题、影响和处理办法；没有问题则继续。关键要求仍不明确时，根据已有授权说明采用的假设，或在确实需要用户决定时提问。已经披露且没有变化的问题不重复提醒。

这里要保留一个边界：**触发类型可以程序化决定取证方式，但“哪些记录最相关”还需要实验编号、调用关系或 Plan 步骤等关联信息。** 没有关联时，应允许补取上下文，不能把一次小范围检索没找到证据当成最终结论。

日常主动检查采用 **“默认给相关证据 → 必要时补查”**；原来的三个接口保留给用户另行要求的完整任务核对。

1. **触发。** 分别记录采用前、首次汇报前和 Stop 续跑的发现时机；成功退出也需核对验证范围，结束后纠正不能算及时拦截。
2. **状态。** 保存相关执行时的代码与结果，续读复用冻结材料；新增实验或验证不能沿用执行前检查点背书。凭证仅保留配置／加载状态，文件和 Trace 均检查采集边界。
3. **材料。** 按类型返回有效要求、对应执行与关键实现；结果类同时核对摘要所引用的详细记录，不能只给通过数量。大材料保留明确展开入口。
4. **判断。** 对应要求、实际验证范围与完成声明；区分流程通过、真实调用和有效响应。不把修复后的连接失败扩展为全部实验失败，也不把旧问题继续当作当前实现缺陷。
5. **取证。** 沿具体前提补查入口、配置加载、分支与记录链；记录漏取、多取和错误引用。仅检查待优化函数不足以覆盖独立验证要求。
6. **分类。** 暂保留 result、adjustment、ambiguity。按当前意图分类：采用成功结果属于 result；受阻后调整属于 adjustment。逐类验证，不能用结果类命中推断其他类别有效。
